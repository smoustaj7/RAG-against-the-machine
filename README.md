# RAG Against the Machine

## Description
A Retrieval-Augmented Generation (RAG) system designed to index codebases and documentation, perform lexical and semantic searches, and answer questions grounded in retrieved sources.

## Instructions
### Prerequisites
- Python 3.10+
- `uv` package manager

### Setup & Running
```bash
make install
make run
```
